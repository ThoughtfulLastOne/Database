# Сортировка слиянием (Merge Sort)

Сортировка слиянием — это алгоритм, основанный на принципе «разделяй и властвуй»:
массив рекурсивно разбивается на две половины, каждая из которых сортируется отдельно,
а затем две отсортированные половины сливаются в одну.

Алгоритм начинает с разбиения массива до отдельных элементов (каждый элемент считается отсортированным).
Затем происходит попарное слияние подмассивов с сохранением порядка сортировки.

## Инвариант
На каждом этапе слияния каждый подмассив отсортирован относительно своих элементов.

## Свойства
- **Устойчивость (stable):** равные элементы не меняют свой относительный порядок.
- **Память:** требует O(n) дополнительной памяти для хранения временных подмассивов.

## Трудоёмкость
- **Все случаи (лучший, средний, худший):** O(n log n) сравнений.
- **Память:** O(n) дополнительной памяти.

## Когда использовать
Сортировка слиянием эффективна для больших массивов и стабильна, поэтому часто применяется в системах, где важна устойчивость сортировки.
