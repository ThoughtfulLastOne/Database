# Быстрая сортировка (Quick Sort)

Быстрая сортировка — это алгоритм, основанный на принципе «разделяй и властвуй»:
выбирается опорный элемент, массив делится на две части — элементы меньше опорного и элементы больше опорного, после чего каждая часть сортируется отдельно.

## Итеративная версия

В данной реализации используется стек вместо рекурсии:
- В стек помещаются границы подмассивов.
- На каждом шаге извлекается отрезок [left, right].
- Выполняется разделение относительно опорного элемента.
- Опорный элемент помещается на правильную позицию.
- Границы новых подмассивов добавляются в стек.

## Инвариант
После каждого разделения опорный элемент находится на своей окончательной позиции.

## Свойства
- **Нестабильная (unstable):** относительный порядок равных элементов может измениться.
- **Память:** O(log n) для стека (в среднем).

## Трудоёмкость
- **Лучший и средний случай:** O(n log n) сравнений.
- **Худший случай (неудачный выбор pivot):** O(n²), например, если массив уже отсортирован, а pivot берётся последним.
- **Память:** O(log n) для стека (в среднем).

## Когда использовать
Быстрая сортировка — один из самых быстрых алгоритмов на практике, особенно на больших массивах.
Она широко используется в стандартных библиотеках (например, в C++ (std::sort), Java (Arrays.sort), Python (Timsort — гибрид с вставками)).

## Улучшения
- Выбор pivot из середины или случайного элемента снижает вероятность худшего случая.
- При малых размерах подмассивов можно переключаться на сортировку вставками для ускорения.
